# 儿童发展心理学评估框架

> 用于解读儿童与 AI 对话中的行为表现。本框架基于主流发展心理学（皮亚杰认知发展阶段、埃里克森社会心理发展阶段、语言发展里程碑）的**家长观察视角**，不构成医学诊断。

## 一、年龄段特征速查（3-6 岁学龄前期）

### 认知发展（皮亚杰·前运算期）
- **特点**：以自我为中心、象征性思维、不可逆推理、泛灵论（认为万物有生命）
- **在对话中的体现**：
  - 给玩具/角色起名、编故事
  - 认为怪兽会"复活"、动画角色"真的存在"
  - 分不清"主观想法"和"客观事实"
  - 过度关注自己的视角，难理解别人想法
- **家长关注点**：是否在 5-6 岁逐渐出现"去中心化"（能换位思考）、理解守恒概念

### 语言发展（3-6 岁）
| 年龄 | 典型里程碑 |
|---|---|
| 3 岁 | 300-500 词，能说短句，爱问"为什么" |
| 4 岁 | 1000+ 词，会讲简单故事，能数到 10 |
| 5 岁 | 1500-2000 词，会讲较长故事，能数到 20+，会用复杂句 |
| 6 岁 | 能复述完整故事，读写前技能，数到 100 |

- **叙事能力**：5 岁应能讲"有开头-冲突-结局"的简单故事；6 岁能讲更复杂的多角色故事
- **主动提问**：是好奇心和语言发展的双重标志
- **同音错字/发音**：5 岁仍可能混淆某些声母韵母（zh/ch/sh、n/l 等），多数 6-7 岁完善；若 6 岁后明显异常可咨询语言评估

### 社会情绪发展（埃里克森·主动对内疚）
- 核心任务：发展**主动性**，在探索中获得"我能做"的信心
- 表现：爱问问题、爱尝试、爱主导游戏、会为失败内疚
- 关键：这个阶段孩子需要**安全的环境去尝试和犯错**

### 游戏发展
- 3-4 岁：平行游戏 → 4-5 岁：联合游戏 → 5-6 岁：合作游戏
- **象征性游戏/幻想游戏**（扮演、假想伙伴）在 4-6 岁达到高峰，之后逐渐被规则游戏取代
- **规则游戏兴趣的出现**（5-6 岁）是认知成熟的重要标志

## 二、常见表现的解读对照表

| 表现 | 发展阶段解读 | 是否需要关注 |
|---|---|---|
| 说"屎尿屁"脏话 | 污言秽语期：通过禁忌词体验语言力量感 | 否，正常；冷淡处理即可 |
| 战斗幻想、"打死怪兽" | 象征性游戏：通过想象处理攻击冲动和恐惧 | 否，只要区分幻想与现实 |
| 幻想伙伴（假想朋友） | 情感联结与想象力发展，常见于独生子女 | 一般否；若长期替代真实社交才需关注 |
| 计较输赢、自己定规则 | 认知过渡期：正在建立秩序感和公平感 | 否，正向引导规则游戏 |
| 喜欢重复 | 练习效应、语言节奏游戏、获得掌控感 | 否 |
| 生气后快速恢复 | 情绪弹性好 | 是优点 |
| 主动提问 | 好奇心 + 语言发展 | 是优点 |
| 讲长故事 | 叙事能力发展 | 是优点 |
| 模仿关心他人（"别怕""我来帮你"） | 共情萌芽 | 是优点 |

## 三、评估维度

### 1. 语言发展
- 平均句长（MLU）：5 岁约 4-6 词/句
- 叙事结构：是否有开头/冲突/解决/结局
- 词汇多样性：书面词、连接词（虽然/但是/因为/所以）
- 主动提问的数量与质量
- 数数/算术能力（与年龄对照）
- 语音转写中的同音错字需区分"发音问题"还是"ASR 误差"

### 2. 认知发展
- 幻想与现实边界是否清晰（关键健康指标）
- 能否记住并复述剧情、规则
- 分类、计数、比较能力
- 因果推理（"因为…所以…"）

### 3. 情绪发展
- 积极/消极情绪比例（表情符号、情绪词）
- 生气诱因（是否合理、是否频繁）
- 情绪恢复速度（情绪弹性）
- 是否有反复出现的恐惧/焦虑主题
- 是否通过游戏处理情绪（如"怪兽装死"投射）

### 4. 社会性发展
- 是否有真实同伴（名字、活动）
- 分享、轮流、合作能力
- 照顾他人行为（喂、保护、安慰）
- 依恋对象（幻想伙伴 vs 真实家人）
- 对 AI 的依赖程度

### 5. 兴趣与性格
- 主题偏好（力量幻想/幽默恶搞/规则游戏/知识学习）
- 主导型 vs 跟随型
- 注意力持续时间

## 四、给家长的建议框架

按「✅ 放心 / 🌱 引导 / ⚠️ 留意」三档组织：

**✅ 放心**：符合年龄段的正常表现，不干预（脏话、战斗幻想、计较输赢等）

**🌱 引导**：顺势而为，把天赋/兴趣变成亲子互动的机会
- 叙事天赋 → 让孩子讲故事、录下来、画出来
- 规则兴趣 → 引入棋类、桌游、扑克
- 照顾他人 → 表扬，给予真实照顾任务（宠物、弟弟妹妹）
- 情感需求 → 高质量陪伴

**⚠️ 留意**（需结合上下文，必要时咨询专业人士）：
- 持续严重负面情绪（哭闹、退缩、攻击真人）
- 反复恐惧且影响日常
- 幻想与现实长期混淆
- 完全无真实同伴
- 单日 AI 使用时间过长（建议 ≤1-2 小时，大人陪伴）

## 五、边界声明

- 本框架用于家长观察与理解，**不提供诊断**
- 每个孩子发展速度不同，个体差异正常
- 若家长有真实担忧，建议咨询儿童心理/发育专业人士
- AI 对话只是孩子生活的一个侧面，要与家庭、学校、同伴的真实情况结合判断
